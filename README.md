### 🚀 Featured Project

#### **LightningChat** – *Zero‑server, offline‑first encrypted messenger*

- Designed a **high‑performance WebSocket relay** with a custom binary protocol (varint‑based) that reduced frame sizes by **60%** and enabled sub‑millisecond parsing.
- Replaced JSON with **Protocol Buffers** in REST APIs – cutting payloads by **40%** and deserialisation time by **5×**.
- Implemented **end‑to‑end encryption** (X3DH + Double Ratchet) inside a Web Worker, ensuring all messages and calls are encrypted **before** they touch the wire.
- Built a **fully offline‑first engine** on IndexedDB – messages are queued when offline and instantly flushed upon reconnection, guaranteeing **100% delivery** with zero server storage.
- Integrated **real‑time voice/video calls** via WebRTC, signalled through the same encrypted WebSocket channel, maintaining E2EE boundaries.
